# API Endpoints for WeFit Game

`GET health_check/` - Check if backend is working

`POST game/start/` - Start the game  (Payload: session id)

`POST game/sync/` - Make move in the game (Payload: session id, movement type)

`POST game/end/` - Ends the game (Payload: session id)
